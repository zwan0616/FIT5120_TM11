This document describes some changes to be made to the meal-maker game, see `app/(tabs)/heroWorld/meal-maker.tsx`

1. Add a back button to the top left corner of the round screen (the screen displayed when a round is ongoing).
2. This back button should navigate the user back to the start game screen. Additionally, the OS back button/gesture should also navigate the user back to the start game screen instead of the  HeroWorld screen as it is currently.
3. Add an options menu which can be opened with a button in the top right of the start game screen. There should be two settings available for now. The settings should be stored locally independent from the user profile. The first setting is a volume control slider which controls the sounds in the game. This setting should affect the menu sound, the round sound, and the in game sound effects, see `app/(tabs)/heroWorld/meal-maker.tsx`, `hooks/games/useGameEngine.ts`. The next setting should be a game difficulty setting with three options available: easy, medium, hard. This setting should affect the speed variables in the game config and the points awarded (via a points multiplier). The harder the difficulty, the faster items fall, and the higher the multiplier, see `constants/GameConfig.ts`.
4. Additionally, upon completing a game, the score should added to the `totalPoints` field in the user profile (if a user profile exists). But this can only be done at most 5 times per day. After points are awarded from completing the game 5 times, additional games completed on that day should no longer add their points to the `totalPoints` field. Add a UI element in the game over screen with animations to show this to the user.
